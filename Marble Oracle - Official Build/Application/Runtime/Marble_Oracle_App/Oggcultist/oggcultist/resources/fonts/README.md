# Uberata Clear v3.0 — bundled by default

Only this original user-supplied TTF is used for Oggcultist's GUI typography,
including headings, navigation, metadata, settings, album-cover lettering and
its dynamically generated sidebar wordmark. The app privately registers the
TTF from this directory; no first-run font ZIP, font import, cache or system
installation is required. Existing cover images are never rewritten.

- Uberata-Clear.ttf: exact user-provided v3.0 font (SHA-256 shown in `oggcultist/fonts.py`)
- OFL_UBERATA_CLEAR.txt: SIL Open Font License attribution and conditions
- NOTO_SOURCE_NOTICE.md: original derivative-font source attribution

For other writing scripts not represented by the bundled font, the album-art
renderer may select a local fallback font to avoid empty/missing glyphs. The
application user interface itself uses the bundled family for all text roles.
