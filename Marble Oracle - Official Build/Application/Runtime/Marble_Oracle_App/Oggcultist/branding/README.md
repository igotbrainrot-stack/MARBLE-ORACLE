# Oggcultist branding — approved O/G/G identity

Current approved identity: `approved-ogg/` includes the reference image, vector paths,
foreground/transparent variants, favicons and all platform icon sizes. The active
in-app PNG and ICO files live in `oggcultist/resources/`; `gui/brand.py` loads the
approved screenshot-derived artwork. Source variants also appear under
`original-identity/`. Do not run any older generator that reinstates obsolete branding.

Normal UI font: bundled Uberata Clear v3.0 only. The geometric wordmark is image art.
No sound-wave, record, radio or other audio metaphor should replace the user's logo.
