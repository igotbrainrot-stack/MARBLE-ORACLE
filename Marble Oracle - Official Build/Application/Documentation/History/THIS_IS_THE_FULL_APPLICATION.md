# Marble Oracle — Complete application (ASCII foreground fix)

This is the complete classic five-panel Marble Oracle application, not a patch.
It includes the ASCII statue foreground contrast fix, Tarot / Runes mode toggle,
24 rune flip animation strips, bundled Uberata Clear font, application data,
and Windows and Linux launchers.

## Windows 11
Extract this complete folder. Double-click `Marble_Oracle.pyw` (Python 3 with Tkinter must be installed). Alternatively use `Launch_Marble_Oracle.vbs`. This is a Python-source distribution, not a standalone EXE.

## Linux Mint
Extract this complete folder. Run `./install_linux_desktop.sh` once (from a terminal in the extracted folder) to create the console-free app-menu launcher. Or use `./Marble_Oracle_Linux.sh` for troubleshooting. Python 3 and `python3-tk` are required.

## Verified here
The Python source compiles, the ZIP file passes integrity validation, and the required rune/font assets exist. Native Windows 11 and Linux Mint desktop behaviour is not verified in this packaging pass. See ASCII_CONTRAST_FIX.md and START_HERE.md for earlier test information.
