# Marble Oracle — Classic Layout / Modern Ember

This is built from the **original PR17 source** included in the user upload, not from the stripped-down Studio interface. All the original modules and supporting media remain.

## Layout
Archive and Latin are on the left; the Wire remains in the middle; markets and cards are on the right. The passphrase bench, legacy tabs, click targets, keyboard shortcuts and view/grade switching remain in their existing source. The layout coordinates have not been modified.

## Changes
- Warm Oggcultist Ember colour roles replace the harsh neon scheme in normal mode.
- Panel backgrounds, separators and headings are quieter.
- Decorative viewfinder brackets are suppressed in normal mode.
- Uberata Clear v3.0 is bundled, privately registered and used for the Tk UI.
- Default launcher uses the original classic multi-panel screen **without the oversized photographic CRT bezel**.
- `Marble_Oracle_ORIGINAL_CRT.bat` opens the older hardware/retro appearance as an alternative.

## Launch
Run `Marble_Oracle.bat` from the extracted directory. Requires Python 3 and the packages/requirements from the original project; it uses the original bootstrap.

## QA limitation
Compiled successfully; virtual-display and Windows real-device behaviour are separate checks. The classic hardware renderer is preserved but not visually certified here.
