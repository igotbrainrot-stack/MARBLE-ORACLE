# Marble Oracle — Ember visual unification and setup recovery

## Visual changes
- Same Oggcultist 2.0.6 palette for Oracle panels, navigation, footers, and passphrase controls.
- Low-amplitude, deterministic warm-grain texture inside every Oracle panel, rendered *under* all text and artwork.
- Inset reading/entry fields use the Oggcultist sunken surface.
- Restrained secondary buttons; the primary accent remains orange.
- The Wire quotation uses ivory, muted tan and amber instead of green, leaving market up/down status colours unchanged.
- Original five-panel layout, tab positions, Rune/Tarot controls, Grade presets, and Passphrase five-card layout unchanged.
- Uberata Clear font remains packaged and used throughout.

## Setup / recovery
- Linux media-install failures are optional and do not block core application startup.
- FFmpeg detection and startup no longer crash because a private Oggcultist media path cannot be imported.
- Requirements manager remains open after installation for explicit START, shows failures, and logs them.

## Remaining checks
- Native Windows 11 and physical Linux Mint appearance/playback remain unverified in this container.
- OS-level FFmpeg installation requires authorization and was tested with simulated commands only.
