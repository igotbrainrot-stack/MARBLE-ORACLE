# Marble Oracle — technical handover

## Project identity
Keep the original five-panel dashboard: archive + Latin left; prominent Wire centre; markets + cards right. Ember charcoal and restrained orange palette, Uberata Clear only. The previously removed sponsor feature must not return.

## Entrypoints
- Main GUI: outer `Marble_Oracle.pyw`, calls `oracle_bootstrap.launch` with `--no-bezel --os-frame`.
- Linux: `Marble_Oracle_Linux.sh` from desktop entry generated by `install_linux_desktop.sh`.
- Windows: double-click `.pyw` or optional `Launch_Marble_Oracle.vbs` when pyw is available. Windows `.bat` is for diagnostics only.
- Optional classic hardware: `Marble_Oracle_Linux_Original_CRT.sh` and `Marble_Oracle_ORIGINAL_CRT.bat` (dependencies vary).

## Key code
- `Marble_Oracle_App/marble_oracle.py`: main canvas, layout, interactions, keybindings, selftest.
- `Marble_Oracle_App/oracle_chrome.py`, `oracle_skin.py`: visual treatments.
- `Marble_Oracle_App/marble_uberata.py`: private cross-platform Uberata font loading.
- `Marble_Oracle_App/oracle_bootstrap.py`: dependency conditions, error handling, startup.
- `Marble_Oracle_App/oracle_assets.py`: external resources, user state, cache paths.
- `oracle_latin.py`, `oracle_sententiae.py`, `oracle_dicekey.py`, `oracle_wire.py`, `oracle_feeds.py`, `marketdata.py`: subsystems.
- `data/`: bundled assets. Keep audio/card/deck archives when repackaging.

## Build and test
Python 3 with Tkinter required. Run `python -m compileall -q Marble_Oracle_App` and GUI selftest `xvfb-run -a python3 Marble_Oracle_App/oracle_bootstrap.py --selftest --no-network --no-bezel --os-frame` on Linux (where xvfb is available). Use `Marble_Oracle.pyw` on Windows after installing Python with Tk. Don't reinstall dependencies automatically at program startup. The optional CRT requires Pillow.

## Preservation rules
Do not change five-panel geometry, remove features, or reintroduce deleted sponsor assets. Preserve saved state in XDG state / LOCALAPPDATA. Keep user-supplied Uberata and its licence bundled. Changes should be small, tested and reversible. Native Windows click-through and audio tests remain required.

## Scope of current pass
Cross-platform console-free launch hardening, bundled icon, font consistency, diagnostic logging, documentation, cleanup in runtime builds. Consult `REFINEMENT_REPORT.md` for validation and limitations.

## Archive readability update
The Plate Vault ASCII statue colour ramp is now a warm high-contrast ten-step palette on Ember surfaces. This lifts previously invisible dark shading while preserving the original statue geometry, size, animation, controls and all other panels.
