## Subsystem notes

Written when each part was built; still accurate for how that part works, but each is a snapshot of its release.

- `Workspaces/`: EIDOLITH (reliability, speed research, naming, player pages, file selection), AUGURSPEX (provider research and integration notes), Oggcultist integration and textures, runes, ASCII statues, HOME sidebar, Touch Type.
- `Launch/`: first-run requirements, the media-tools installer, console-free launch, the launcher repair.
- `Reference/EIDOLITH_design_document_v0.1.md`: the original design brief, unchanged.
- `Research/`: the two market-data research PDFs. In the release ZIP only; not kept in Git.

## History

`History/` keeps every earlier handover (`HANDOVER_0.4.9.3-0.4.9.5.md` for the most recent ones), changelog, audit report and manifest, and `History/ReleaseNotes/` the notes for 0.4.7.1 to 0.4.9.2. They describe the program as it was; launch instructions in them may be obsolete.
